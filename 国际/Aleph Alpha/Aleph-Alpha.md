# Aleph Alpha

> **近一月（2026-09-22 → 10-22）：无任何新动态。** 作为独立厂商的历程已于 2026-04-24 结束（并入 Cohere），此后不再有新模型或产品发布。
> 一个值得记的背景对照：本月欧洲主权 AI 的注意力与资本集中流向 **Mistral**——其完成约 30 亿欧元 D 轮（估值约 210 亿欧元、三星领投）并发布万亿级 Mistral Large 4。合并后的 Cohere 虽是"跨大西洋主权 AI"平台的欧洲 arm，但本轮并无欧洲侧的新动作披露。

欧洲"主权 AI"运动最完整的参考案例：七年、五个阶段，从"德国的 OpenAI"到被加拿大 Cohere 合并。它的结局说明了一件事——**主权叙事正确，但规模决定谁能留在前沿**。

### T-Free 值得一提

T-Free 完全取消传统分词器，直接在字符级处理文本：

- 嵌入层参数最多减少 **85%**
- 非英语语言最多快 **200%**
- 通用性更强（适用于所有语言与专业词表）

这是 Aleph Alpha 在架构层面留下的最有辨识度的资产。

## 主权争议（未解决）

德国多个联邦机构与三个州的合同含明确的**"必须由欧洲控制"主权条款**。合并后实体由 Cohere（加拿大）股东控股约 90%，公司注册地可能为加拿大或美国特拉华：

- **支持方的辩护**：加拿大在结构上不受美国域外法律（CLOUD Act、FISA 702）约束，这是任何美国供应商都无法声称的。
- **定位话术**：官方将其描述为"**加拿大 + 德国的主权替代方案，对抗美国超大规模云厂商**"，而非"纯欧洲主权方案"。
- **结论**：是否满足"欧洲控制"条款，截至 2026-09 未有定论。

## 五条结构性教训

1. **方向正确、时机偏晚**：2024 年中转向企业主权定位是对的，问题在执行时间。
2. **创始人身份认同有代价**：Andrulis 对"欧洲 OpenAI"叙事的执着，被认为在运营上代价高昂。
3. **融资头条要拆开看**：2023-11 的"5 亿美元 B 轮"实为约 1.1 亿欧元真实股权 + 3 亿欧元研究子公司 + 6000 万欧元订单承诺，约 4.5 倍通胀式表述。
4. **主权 ≠ 规模**：主权叙事能拿到政府订单，但前沿竞争需要资本与算力的量级，欧洲初创难以独自支撑。
5. **结果不是失败，而是迟到但更可防守的定位**：合并后定位比合并前更站得住。
