# Llama 3.1

## 基本信息
Llama 3.1 于 **2024-07-23** 发布，在 Llama 3（2024-04-18，8B/70B）基础上新增 **405B** Dense 模型，并把全系上下文扩展到 **128K**。

## 关键意义
- **当时最大可公开下载的模型**：405B + 128K 的组合，让开放权重首次在规模与长上下文上逼近闭源前沿。
- 405B 的发布被视为开放权重对闭源旗舰的一次正面挑战，也是后续 Llama 4 转向 MoE 前 Dense 路线的顶点。
- 128K 成为后续 3.2 / 3.3 全系标准配置。

## 对比脉络
- Llama 3（2024-04-18）：8B / 70B，8K 上下文。
- Llama 3.1（2024-07-23）：+ 405B，128K。
- Llama 3.2（2024-09-25）：1B / 3B 端侧 + 11B / 90B 视觉，首个原生多模态。
- Llama 3.3（2024-12-06）：70B，以低成本匹配 405B 质量——405B 的实用价值被 70B 部分替代。

## 备注
- 405B 需多卡部署（bf16 全精度门槛高），实际生产中常被 70B / 3.3 70B 取代。
- 来源：Meta llama-models（GitHub）、aiwiki（meta_ai）、benched.ai。
