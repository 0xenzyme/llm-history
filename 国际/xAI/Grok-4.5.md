# Grok 4.5

## 基本信息

Grok 4.5 于 **2026-07-08** 上线 xAI API（马斯克 07-08 在 X 预告、07-09 正式对公众开放），是 **SpaceX 收购 xAI 之后的第一个大版本**，马斯克将其定位为"Opus 级"模型，强调速度、token 效率与成本。发布即刻进入 **Cursor、Grok Build 与 xAI 控制台**；欧盟因审查延迟，**07-17** 才在 API 控制台开放（另有源记 07-16）。

## 关键参数

- **新基座 V9**：约 **1.5T 参数**（内部代号 V9-Medium），训练于数万张 NVIDIA GB300，xAI 称为此重写了稳定性与优化技术。
- **与 Cursor 联合训练**：SpaceX 于 2026-06 同意以约 **600 亿美元**收购 Cursor（预计 Q3 完成），4.5 使用了 Cursor 的真实开发者会话数据（调试轨迹、多文件 diff、用户纠正模式）进行训练。
- **上下文 500K**；文本 + 图像输入，文本输出；推理档位 low / medium / **high（默认）**。
- **定价 $2 / $6**（每百万 tokens，缓存输入 $0.30）——不到 Opus 4.8（$5/$25）的一半、Fable 5（$10/$50）的几分之一。
- 速度：官方称 80 tokens/s 且 token 效率为 Opus 4.8 的 **4.2 倍**；第三方 TryAI 实测首 token <0.5s、整体约 110 tokens/s（约为 GPT-5.5 与 Opus 4.8 的两倍）。

## 关键成绩

- **Artificial Analysis 综合智能指数 54**（第 4），较 Grok 4.3 提升 **16 分**；**Coding Agent Index 76**，与 GPT-5.5 基本持平。
- **Harvey 法律智能体基准第 1**；GDPval-AA v2 第 4。
- Terminal-Bench 2.1 **83.3%**（GPT-5.5 83.4%、Fable 5 84.3%，基本持平）；DeepSWE 1.1 **53%**（落后 GPT-5.5 的 67%、Fable 5 的 70%）。
- **效率亮点**：SWE-Bench Pro 上平均仅输出约 **15,954 tokens** 完成任务，而同类领先模型约 67,020 tokens（约四分之一）。
- 发布后直接成为 **Cursor 默认模型**。

## 代际意义

- xAI 路线从"通用旗舰"切到**编码 / 智能体 / 知识工作 + 价格战**：性能贴近前沿、价格砍到对手的一半以下，打法类似 DeepSeek 在中国市场的策略。
- 上下文策略转向：4.3 的 1M 回缩到 **500K**，换取成本与长程智能体稳定性，此后 4.6 / 4.7 沿用。
- 与 Cursor 的资本 + 数据双重绑定，是 Grok 后续"编码 Agent 优先"路线的起点（延续至 4.6 的更长 agent 轨迹、4.7 的 Grok Build 记忆）。

## 争议事件

- **2026-07-13**：独立安全研究员发现 **Grok Build CLI 在用户关闭"改进模型"选项后，仍会将整个 Git 仓库打包上传到 xAI 的 Google Cloud 存储桶**；马斯克承认属实，承诺删除相关数据并上线 `/privacy` 命令。
- **2026-07-15**：xAI 宣布**开源 Grok Build**、重置用户使用限额，并称自 07-12 起已为所有用户默认禁用数据保留。
- 同月马斯克在评测评论区称 Kimi K3"令人印象深刻"，将其列为 Grok 4.5 的重点追赶目标；月之暗面企业业务负责人 07-21 回应"希望他们出来掰掰手腕"。
