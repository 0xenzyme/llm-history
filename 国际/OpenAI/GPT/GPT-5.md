# GPT-5

GPT-5 是 OpenAI 首个"统一系统"，把 GPT 对话线与 o 推理线收敛到一套实时路由器之下。

## 发布时间线

- 2025-08-07：GPT-5 发布，免费用户首次可用；同步推出 mini / nano / Pro / Thinking 变体。
- 后续快速迭代：GPT-5.1（2025-11-12）→ GPT-5.2（2025-12-11，三档）→ GPT-5.3（2026-02~03）→ GPT-5.4（2026-03，原生 computer-use）→ GPT-5.5（2026-04-23，1M+ 上下文）→ GPT-5.6（2026-07，Sol/Terra/Luna）。

## 关键参数

- 上下文：400,000 token 输入，128,000 token 输出（发布规格）。
- 多模态：文本 + 图像输入、文本输出。
- 推理模式：内置实时路由器，按请求自动决定 fast / thinking，用户也可调 reasoning effort 与 verbosity。
- 定价（发布价）：输入 $1.25 / 百万 token，输出 $10.00 / 百万 token。

## 关键事实

- **代际分水岭**：首次把 o 系列推理与 GPT 对话统一，消除手动选模型；较 GPT-4o 事实错误降约 45%，SWE-bench Verified 74.9%（vs 4o ~54%）。
- **路由架构**：不是单一模型，而是"快速子模型 + 深度推理子模型 + 路由器"的系统，被逐步复用到后续 5.x 全部点发布。
- **评测（发布时官方）**：AIME 2025 94.6%（数学）、GPQA Diamond 88.4%（博士级科学）、MMMU 84.2%（多模态）。

## 备注

- GPT-5 之后 OpenAI 进入"软件式快速迭代"节奏，点发布（5.1→5.6）携带了绝大部分真实能力提升。
- 退役关联：o 系列作为独立 ChatGPT picker 在 GPT-5 发布后退役，能力并入统一路由。
