# o 系列（推理模型）

厂商：OpenAI
开源/闭源：闭源
定位：训练为"回答前先思考"的链式推理模型，擅长数学/代码/科学/视觉推理

## 版本演进

| 模型 | 发布时间 | 备注 |
|---|---|---|
| o1-preview / o1-mini | 2024-09-12 | 首个推理模型（预览） |
| o1 | 2024-12-05 | 正式 GA（全量） |
| o3-mini | 2025-01-31 | 低成本推理，STEM 优化 |
| o3 / o4-mini | 2025-04-16 | 视觉推理 + 自主工具调用（搜索/Python/图像） |
| o3-pro | 2025-06-10 | 高算力版，更长思考更可靠 |
| （并入 GPT-5） | 2025-08-07 | ChatGPT picker 退役 o 系列，能力并入统一路由 |

## 备注

- o 系列起源于 2024-09 的 o1-preview，确立"推理时计算（test-time compute）"范式：模型生成内部思维链后再作答。
- 关键节点：o3（2024-12-20 公布、2025-04-16 发布）在 ARC-AGI 高算力配置达 87.5%，Frontier Math 解 25.2%（此前无模型超 2%）。
- 命名：跳过 "o2"（避免与英国电信 O2 混淆）。
- **收敛**：2025-08-07 GPT-5 发布后，o 系列作为独立 ChatGPT 选择器退役；API 上 o3 / o3-pro 仍保留（o3-mini / o4-mini 计划 2026-10-23 关停，由 GPT-5.4/5.5 替代）。
- 来源：OpenAI 官方公告、aiwiki、Wikipedia(o4-mini)、systems-analysis.info。
