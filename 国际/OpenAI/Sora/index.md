# Sora（视频生成）

- 厂商：OpenAI
- 开源/闭源：闭源
- 定位：文生视频 / 图像生视频模型，初步具备物理世界模拟能力
- **状态：已终止（Discontinued）** —— OpenAI 于 2026-03-24 通知开发者弃用，2026-04-26 关闭 App/网站，**2026-09-24 关闭 API**，此后 OpenAI 产品目录中不再有任何视频生成模型。

## Sora 2 技术规格（历史记录）

- 模型 ID：`sora-2`（720p 标准）、`sora-2-pro`（解锁 1024/1080p）
- 分辨率：`sora-2` 720×1280 / 1280×720；`sora-2-pro` 追加 1024×1792、1792×1024、1080×1920、1920×1080
- 时长：单次 16 / 20 秒；`/v1/videos/extensions` 每次续写 20 秒，上限约 120 秒（最多 6 次）
- 原生音频：单次生成同步产出对话、音效与环境音（非后期合成），这是最难被替代的能力
- 其他：角色参考（`/v1/videos/characters`）、Batch API 半价、可见动态水印 + C2PA 溯源元数据
- 定价：约 $0.10/秒（720p）～ $0.30–0.70/秒（Pro）

## 备注

- **无 Sora 3**：OpenAI 未发布也未宣布任何继任者。同期 `gpt-image-2`（2026-04-21）仅生成静态图，GPT-6 Astra（2026-09-03）是语言模型，均不能生成视频。Sora 团队转为内部 world-model 研究。
- **版权争议**：Sora 2 发布时默认使用受版权保护素材（需权利方 opt-out），发布 72 小时内在抗议后改为 opt-in；水印在发布一周后即被第三方工具破解。
- 该项目此前将"Sora 2 及后续"标记为未核实，2026-09-30 review 时补正为完整停运记录。
