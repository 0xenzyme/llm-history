# Claude 3.5 Sonnet

Claude 3.5 Sonnet 是 Anthropic 2024 年的标志性模型，把"编码 Agent"与"工具使用"推到主流，是 Claude Code 与 vibe coding 浪潮的直接起点。

## 发布时间线

- 2024-06-20：Claude 3.5 Sonnet 首发。
- 2024-10-22：升级版（new）发布，同场推出 Claude 3.5 Haiku；computer use 公开 Beta。

## 关键参数

- 上下文：200K token；模态文本 + 图像输入、文本输出。
- 能力亮点：Artifacts（独立预览窗口实时渲染 SVG / 网页 / 代码）、computer use（Beta，可操作桌面光标、点击、输入）。
- 定位：较 Claude 3 Opus 更强、更快、更便宜。

## 关键事实

- **编码 Agent 起点**：3.5 Sonnet 与 Artifacts 催生了 vibe coding 浪潮（Karpathy 于 2025-02 造词），并直接孕育 Claude Code。
- **computer use 先行者**：首个公开桌面操作能力的主流模型。
