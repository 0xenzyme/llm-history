# Claude Fable 5.1 / Mythos 5.1

Fable 与 Mythos 是 Anthropic 2026 年新增的前沿实验线，定位高于 Opus，面向编码与知识工作，是 Claude 家族当前最前沿档。

## 发布时间线

- 2026-04-07：Claude Mythos（preview）有限可用。
- 2026-06-09：Claude Fable 5 与 Mythos 5（preview）发布，但随即 Suspended（撤回）。
- 2026-09-01：稳定版 Claude Fable 5.1 与 Mythos 5.1 发布，定位"最先进模型，编码与知识工作"。

## 关键参数

- 上下文：1,000,000 token 输入，最大输出 128,000 token（与 Opus 5 同代）。
- 定价（Fable 档）：$10 输入 / $50 输出（每百万 token），高于 Opus 5 的 $5/$25。
- 定位：Fable/Mythos 为 Anthropic 当前最前沿档；Opus 5 被官方描述为"近 Fable 5 智能、半价"。

## 关键事实

- **发布即撤回的前例**：Fable 5 / Mythos 5 在 2026-06-09 同日发布并被 Suspended，稳定版以 5.1 于 09-01 落地，反映该线仍在快速迭代/实验。
- **最高定价档**：Fable 5.1 的 $10/$50 是 Claude 家族迄今最高标价，对应其顶级智能定位。

## 备注

- 来源：Anthropic 官方公告与 model card（2026-09）、维基百科。
- 该线（Fable/Mythos）是否长期独立于 Opus 体系、两者如何分工，截至 2026-09 仍待观察。
