# Claude Opus 5.5

Claude Opus 5.5 是 Anthropic 截至 2026-09-22 的最新 Opus，官方称其在大多数工作上达到 Fable 5.1 水平、运行成本较 Opus 5 低 40%。

## 发布时间线

- 2026-09-22：Claude Opus 5.5 发布（约 90 分钟后 OpenAI 放出 GPT-6 Sol / Luna 形成直接对标）。

## 关键参数

- 上下文：1,000,000 token 输入，最大输出 128,000 token（与 Opus 5 同）。
- 定价：$4 输入 / $20 输出（每百万 token）—— 较 Opus 5 的 $5/$25 标价降 20%；官方称典型工作负载运行成本低 40%。
- 定位：Opus 5 的补强版，性能逼近顶级 Fable 5.1、价格显著更低。

## 关键事实

- **对标 GPT-6 Sol/Luna**：与 OpenAI 同日（09-22）发布的 Sol（$2/$10）/ Luna（$0.10/$0.50）形成正面竞争；Opus 5.5 的 $4/$20 介于两者之间、定位高端。
- **运行成本叙事**：Anthropic 强调"40% less to run than Opus 5 on typical workloads"，指向实际推理成本而非标价。

## 备注

- 来源：Anthropic 官方公告、DataNorth / AIxploria（GPT-6 Sol/Luna 对比报道，2026-09-22~25）。
- 同日 Anthropic 还于 09-28 发布 Sonnet 5.5（快 30%、便宜 30%）。
