# Hy3

## 基本信息
- 厂商：腾讯
- 系列：混元（HY 时代首款旗舰，"Tencent Hy" 品牌）
- 类型：大语言模型（MoE），面向推理 / Agent / 编程 / 办公生产力
- 开源/闭源：开源（Apache 2.0，商业友好）

## 发布时间线（preview → 正式版）
- 2026-01 底：腾讯混元启动底层基础设施重建（由首席 AI 科学家姚顺雨带队重构预训练与强化学习基础设施），Hy3 Preview 启动训练
- **2026-04-23：Hy3 preview 发布并开源**（GitHub / Hugging Face / ModelScope / GitCode 同步，距重建启动约三个月，是混元重建后训练的第一个模型）
- **2026-07-06：Hy3 正式版发布**（preview 转正，基于 preview 通过强化学习增强 + 数据质量/多样性提升，进一步拉开性能）
- 2026-07-08：首发平台 WorkBuddy 因访问量过大需排队，团队随后资源扩容
- 2026-07-14：发布 Hy3 极致量化版本
- 2026-07-27：QQ 宠物升级并接入 Hy3
- 2026-08-31：WorkBuddy 内 Hy3 限免截止（此前全球用户免费体验）

> 注：preview 到正式版间隔约两个半月。腾讯采用"preview 先行、正式版跟进"的策略，正式版并非重新训练，而是在 preview 基础上打磨稳定性、成本与产品集成。

## 关键参数（正式版与 preview 一致）
- 总参数量：295B，激活 21B（每次推理仅用约 7% 参数，效率型 MoE）
- 架构：Mixture-of-Experts，80 层；192 个专家、Top-8 激活；64 个 Query 头、8 个 KV 头（GQA）；隐藏维度 4096
- 上下文：256K tokens
- 思考模式：快慢思考融合（hybrid fast-and-slow-thinking）
- 许可证：Apache 2.0

## 正式版相对 preview 的提升
- 经真实业务场景与全球开发者反馈持续打磨，稳定性、成本效率提升
- Agent 能力显著增强：WorkBuddy 中任务成功率从 72% 跃升至 90%，平均耗时缩短 34%
- 推理、指令遵循、长上下文、代码生成、智能体执行与幻觉控制全面改进
- 发布后一周，API 调用量较上一代模型增长超 68 倍，并在 OpenRouter 全球大模型调用量总榜排名第一

## 定价（API，腾讯云 TokenHub）
- 输入：1 元 / 百万 tokens
- 输出：4 元 / 百万 tokens
- 命中缓存：0.25 元 / 百万 tokens

## 产品集成
已接入腾讯多款产品作为底层 AI 引擎：WorkBuddy / CodeBuddy、元宝（并新增 Agent 能力）、Marvis、ima、微信公众平台客服、WeGame（如《流放之路：降临》AI 助手）。

## 备注
- 研发由腾讯首席 AI 科学家姚顺雨领导的团队负责（2025 年底入职后主导基础设施重建）
- 从 2026-01 底重建、4 月 preview 到 7 月正式版，腾讯 Hy 在不到六个月内跑通"基础设施重建 → 产品反馈 → 模型改进"的完整闭环
- 与同期第一梯队相比，Hy3 刻意维持 295B 参数与 256K 上下文（未追 1M 窗口），核心逻辑是压榨既有容量的性能极限，强调实用与成本效率
