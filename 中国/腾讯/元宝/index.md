# 元宝

厂商：腾讯
开源/闭源：闭源（C 端产品，底层为混元 / HY）
说明：腾讯元宝是基于自研混元大模型的 C 端 AI 助手 App，提供 AI 搜索 / 总结 / 写作等能力。

## 版本 / 时间线
| 节点 | 时间 | 备注 |
| --- | --- | --- |
| 元宝 App 正式上线 | 2024-05-30 | 苹果 / 安卓应用商店上线 |
| 接入 DeepSeek-R1 | 2025-02-13 | 与混元一并作答 |
| 灰度接入混元 Turbo S | 2025-03-01 | 快思考模型 |
| 默认模型升级为 混元 T1 | 2025-03 | 用户可切换模型 |
| 接入 Hy3 / Hy4 preview | 2026（持续） | 随混元代际升级，最新底层为 Hy4 preview（2026-08-28） |
| 登顶下载榜 | 2025-02 末 | 中国区苹果免费榜超越 DeepSeek |

## 重点 model 文档
- 元宝为应用层，底层模型见 [混元系列](../混元/index.md)
