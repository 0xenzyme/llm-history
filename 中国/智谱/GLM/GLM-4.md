# GLM-4

## 基本信息
- 发布时间：2024-01-16
- 定位：智谱新一代基座大模型，开启 GLM-4 时代
- 上下文：128K
- 能力：多模态理解、All Tools（网页浏览 + 代码解释器 + 多工具自主调用）、智能体

## 关键参数与能力
- 性能较 GLM-3 提升约 60%
- 多语言（26 种语言）
- 开源支线：GLM-4-9B / GLM-4V-9B（2024-06，9B，128K，网页浏览 + 代码执行）
- 闭源增强：GLM-4-Plus（2024-08，GPT-4o 级）

## 备注
- GLM-4 是智谱从"对话模型 ChatGLM"迈向"通用基座 GLM"的转折点，命名由 ChatGLM 系列收敛为 GLM 系列。
- 奠定后续 GLM-4.5 / 4.6 / 4.7 / GLM-5 的迭代基础。
