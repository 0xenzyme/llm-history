# GLM-5.3-Flash

## 基本信息
- 厂商：智谱 AI（Z.ai）
- 发布时间：2026-08-26（上线并开源 Hugging Face / ModelScope），2026-08-27（官方正式发布）
- 类型：原生多模态大模型（轻量化，GLM-5.3 的 Flash 变体）
- 定位：低成本、高性价比的多模态 Agent / 编程模型，"以更少计算资源实现更强性能"

## 关键参数
- 总参：320B（3200 亿），激活：18B（320B-A18B）
- 层数：45 层（对比 GLM-5.3 的 78 层、GLM-4.5 的 92 层，几乎减半）
- 架构：**稀疏注意力 + 线性注意力混合架构**（首个采用此组合的开源前沿模型），在保持长上下文精度的同时大幅降低长上下文服务成本
- 超连接：流形约束超连接（mHC，manifold-constrained hyperconnection），提升模型规模扩展（Scaling）能力
- 上下文：100 万 tokens（1M）
- 预训练：30T tokens 多模态语料
- 模态：原生多模态——视觉编码能力原生集成，可理解图像 / 视频并生成代码，能在代码循环中利用视觉反馈迭代改进（如前端 / 游戏 / 3D 仿真任务）
- 许可：MIT 开放权重

## 性能（公开基准）
- Artificial Analysis Intelligence Index（AA 综合智能指数）：57 分，进入全球前沿模型能力区间，与 Anthropic Claude Opus 4.8 得分持平
- 全面超越参数量高一倍的 GLM-5.2
- 擅长编程与智能体（Agent）任务

## 性价比 / 定价
- 定价为 GLM-5.3 的 1/10
- 定价为 Claude Opus 4.8 的 1/40

## 国产算力里程碑
- 首个在大规模流量中使用**国产芯片集群**提供服务的模型
- 通过自研高带宽互联网络连接国产 GPU，自研推理引擎 + 针对性内存 / 量化优化
- 与同一硬件初始基线相比，端到端服务性能提升 3 倍，单 token 成本已达主流英伟达 GPU 相当水平
- 例证：无任何外部素材下自主运行 16 小时，搭建约 400㎡ 专业主厨住宅与测试厨房

## 备注
- 该模型曾被匿名以 "Ox Alpha" 之名在海外 OpenRouter / OpenCode 平台发布走红（上线首日冲至 OpenRouter 榜首），后由智谱认领，即 GLM-5.3-Flash。
- 与 GLM-5.3 关系：GLM-5.3 为 744B/40B 旗舰基座（Agentic coding + 网络安全），GLM-5.3-Flash 为 320B/18B 轻量化、原生多模态、低成本变体，二者同属 GLM-5.3 代际。
- 沿用智谱自 GLM-5 起的"国产算力全栈自主"路线（华为昇腾等国产 GPU 训练 + 推理）。
