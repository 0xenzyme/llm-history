# Qwen3

Qwen3 是 Qwen 家族首个全面引入 MoE 与"思考 / 非思考"双模式的代际。

## 发布时间线

- 2025-04-28/29：Qwen3 全系发布，含 Dense（0.6B~32B）与 MoE（30B-A3B、235B-A22B），全系列开源。
- 2025-03-06：QwQ-32B（强化学习推理，已先行）
- 后继：Qwen3-Max（万亿参数闭源，2025-09）、Qwen3-Next（架构，2025-09）。

## 关键事实

- **思考模式切换**：主族统一支持 `/think` / `/no_think`，用户可控制是否走长链推理，兼顾质量与延迟。
- **MoE 主线**：235B-A22B 旗舰（总参 2350 亿、激活 220 亿），128 专家每 token 激活 8 个；另有 30B-A3B 轻量 MoE。
- **语言与生态**：覆盖 119 种语言及方言；开源 30+ 尺寸，强化 Agent、代码、多语言能力。
- **推理分支并入**：QwQ 系列代表的专用文本推理路线被吸收进 Qwen3 主族。

## 备注

- Qwen3 是 Qwen 走向"前沿级开源"的里程碑：235B-A22B 在多数基准上逼近同期闭源模型，而部署成本远低于其总参数量所暗示的水平。
- 架构上仍是纯文本预训练 + 独立 VL checkpoint，原生多模态要等到 Qwen3.5。
