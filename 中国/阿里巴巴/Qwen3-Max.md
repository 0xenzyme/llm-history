# Qwen3-Max

Qwen3-Max 是 Qwen 家族的闭源万亿参数旗舰，代表阿里"开放权重 + 闭源旗舰"双轨策略的顶配。

## 发布时间线

- 2025-09-24/25：Qwen3-Max Instruct 版发布（Qwen 系列首个万亿参数级闭源旗舰）。
- 2026-01-26：Qwen3-Max-Thinking（推理版）推出。
- 后继闭源顶配：Qwen3.7-Max（2026-05-20，最长 1M 上下文） → Qwen3.8-Max-Preview（2026-07-20，2.4T 参数，称将开源"soon"）。

## 关键事实

- **定位**：仅通过阿里云百炼 API 与 Qwen Chat 提供服务，不发布权重、技术报告或模型卡。
- **规模**：万亿参数级，性能作为 Qwen3.5（397B-A17B）"以小胜大"的对照基准——Qwen3.5 以不到 40% 参数量即逼近其顶尖性能。
- **双轨策略**：阿里把最前沿能力放在闭源 Max 系列（3.7 / 3.8），而把可下载、可微调、可自托管的开放权重集中在 3.5 / 3.6 家族，明确区分"拥有模型"与"调用服务"两类用户。

## 备注

- Qwen3-Max 是 Qwen 文档中唯一重点单开的闭源模型，用于对照开放权重家族的能力上限。
- 截至 2026-09，Qwen3.8-Max-Preview 仍以预览服务形式存在，2.4T 参数为公司披露值，"soon 开源"尚无固定权重发布日。
