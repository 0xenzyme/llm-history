# Step 5 Preview

## 基本信息

**2026-09-20**，阶跃星辰发布新一代旗舰基座模型 **Step 5 Preview**，面向 **AI 编程、软件工程、专业知识工作、金融** 等真实世界 Agentic 场景。规格：稀疏 MoE，**总参数 6000 亿、每 token 激活 270 亿**，92 层"窄而深"Transformer，**100 万 token 上下文**，原生支持文本与视觉输入。

定价：输入 **$1.00**、缓存命中 **$0.05**、输出 **$2.70**（每百万 token）。**完整权重计划 2026-10-15 释出**，Hugging Face 仓库截至 2026-09-21 仅有占位文件。

## 成绩

- **Artificial Analysis 综合智能指数 44 分**，**全球开源模型前三**；国产模型中仅次于 45 分的 Qwen3.8 Max 与 GLM-5.3。
- **单任务成本约 $0.71**，官方测算约为 **Claude Opus 5 的 1/8**——用不到 Kimi K3（2.8T 参数）五分之一的体量拿到相同分数。
- 厂商自测（高算力档）：
  - **DeepSWE v1.1：67.7**（仅次于 GPT-6 Astra 74.1 与 Claude Opus 5 74.0，略高于 Kimi K3 Max 67.5）
  - StepCodeBench 49.0；ProgramBench 80.5
  - **Terminal-Bench v4：33.3**（落后 GLM-5.3 的 41.9 与 GPT-6 Astra Max 的 57.9）
- **金融场景**：外部基准 **FrontierFinance**（220 道专业金融问题、11543 项评估标准、覆盖六类投资应用场景）得分 **66.4**，领先 GPT-6 Astra 及其他参评开源模型，位列全球第二。
- **长程任务**：官方称模型可持续约 **22 小时优化 GPU Kernel**，在单张 NVIDIA H100 上把峰值性能提高到 **508 TFLOPS**。

## 定位变化

与 Step 3.x 相比，Step 5 Preview 的叙事重心从"模型能力"转向"**成本-能力帕累托前沿**"：随着 Agent 从"回答问题"走向"完成任务"，主力模型的评判标准不再是单项能力最强，而是能力、成本、效率、场景覆盖四者的平衡。公司认为下一阶段 Scaling 的关键是**提升计算转化为智能的效率**。

场景上，官方点名终端、浏览器、电子表格、设计工具等实际操作环境，并已适配 Codex、OpenCode、OpenClaw、CatPaw、Claude Code、Hermes、Kilo Code 等主流开发工作台。

## 代际意义

- **效率路线的集中兑现**：600B 打 2.8T 的同分，是阶跃"把计算高效转化为智能"这一路线最有说服力的单次论据。
- **金融垂直**：把 FrontierFinance 这类专业金融基准放进旗舰发布的核心叙事，在通用模型发布中少见，指向其 To-B 变现方向。
- **仍在 IPO 窗口**：发布时公司正处于赴港 IPO 关键期（秘密递表、估值传闻最高 120 亿美元），旗舰发布的信号意义大于短期收入意义。

- **自测口径**：除 AA 指数外，DeepSWE / StepCodeBench / ProgramBench / Terminal-Bench v4 均为**厂商自测且基于高算力档**；截至 2026-09-21 无第三方独立编码评测结果。
