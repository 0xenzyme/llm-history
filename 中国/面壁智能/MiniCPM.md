## 分线说明

- **文本基座（MiniCPM x.x）**：密度定律的主战场，追求"同参数下性能更高、成本更低、功耗更低、速度更快"，核心技术为 InfLLM v2 稀疏注意力（稀疏度 5%）+ 高效双频换挡 + BitCPM 4bit 量化（瘦身 90%）。
- **视觉（MiniCPM-V）**：3D-Resampler 实现 96× 视觉压缩；V 4.6 把多模态压到 1.3B / 6GB 内存，是车载与手机落地的实际主力。
- **全模态（MiniCPM-o）**：全双工多模态实时流机制，边听边看边说；o 4.5 的"即时自由对话"是端侧交互体验的分水岭。
- **具身（MiniCPM-Robot）**：2026 年新线，用极小 VLA 模型补齐长时序列记忆，属于端侧路线的自然外延。
- **策略差异**：与云端厂商正面拼参数不同，面壁**不参与参数军备竞赛**，靠"小模型 + 高密度 + 硬件适配 + 开源生态"切入边缘设备市场，是国内除阿里外唯一开源"端侧模型全家桶"的厂商（"**南 Qwen，北面壁**"）。
