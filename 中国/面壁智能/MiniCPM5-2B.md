# MiniCPM5-2B

## 基本信息

**2026-07-19**，面壁智能在 2026 世界人工智能大会（WAIC）上发布端侧文本大模型 **MiniCPM5-2B**；**2026-09-08**，面壁联合 **OpenBMB 开源社区**正式开源该模型，并**同步公开完整训练配方与配套数据集**（UltraData 系列）。

定位：高密度端侧语言基座，**2B 规模上初步实现智能体（Agent）能力雏形**，验证"让 Agent 在手机、汽车等终端本地运行"这条路径。

## 关键成绩

- **Artificial Analysis 榜单 17 分，4B 以下模型全球第一**（"小钢炮"同级最优）。
- **真实任务评测 891 分**（以 1000 分为人类基线），居 4B 以下榜首；远高于 **Qwen3.5 9B（645）** 与参数约为其 6 倍的 **Gemma 4 12B（647）**，更接近人类水平。
- 覆盖通用知识、数学与代码推理、指令遵循、工具调用等维度。

## 技术要点

- **混合思考（Think / No-Think）**：同一套权重通过 `enable_thinking` 开关切换——Think 模式内部生成思维链，显著提升数学 / 代码 / 复杂推理准确率；No-Think 模式跳过思考过程，适合日常问答与摘要。
- **原生 Agent 与工具调用**：训练阶段融入大量 Agent 指令样本，开箱即可完成多步骤任务与函数调用。
- **训练三阶段对齐**：**Agent Midtraining → Agent SFT → Agent RL**。
- **长上下文**：512K（另一口径 128K / 131,072，待核），可一次性读取整本长文档或批量代码文件。
- **量化与部署**：INT4 量化后模型体积约 **1.2GB**，综合能力保留率 **95% 以上**；兼容 Transformers、vLLM、SGLang，提供 GGUF / GPTQ / MLX 量化版本。

## 生态适配

- 已完成 **AMD、英特尔、联发科、高通**等主流芯片适配；
- 联合众智 FlagOS 社区完成 **华为昇腾、英伟达等 9 款芯片的 Day0 适配**。

## 开源范围

不止权重——面壁把"把 Agent 能力训练进端侧模型"的方法一并开放：

- 模型权重（Apache 2.0）；
- 完整**训练 Recipe**（配方）与框架；
- **UltraData 系列数据集**：网页预训练数据 UltraX、代码数据集 UltraData-Code、**50 万条 Agent SFT 样本**、**8 万+ RL 数据**，开发者可复现训练流程。

## 代际意义

- **端侧通用 Agent 的雏形**：此前 Agent 能力主要依托云端大模型，受制于使用成本、响应速度与数据安全；2B 规模跑出可用 Agent 能力，意味着"本地私有化智能体"第一次具备工程可行性。
- **方法开源而非只放权重**：把配方、框架、数据一起交出去，降低了整个端侧生态复现的门槛——这在 2026 年的端侧阵营中属于罕见做法。
- **密度定律的又一次兑现**：2B 打平/超越 6 倍参数量的 Gemma 4 12B，是"以参数效率换部署场景"路线的最新证据。

## 备注

- **上下文口径冲突**：百度百科记 **512K**，第三方技术站记 **128K（131,072）**，本页两说并记**待核**——128K 应为原生训练长度，512K 可能来自长文本档位或外推。
- **参数口径**：名义总参数 25.17 亿、去 Embedding 约 19.8 亿；对外统一称"2B"。
- **发布与开源间隔**：07-19 发布、09-08 开源，间隔约七周，期间官方表示"计划不久后开源"。
