# 盘古 Ultra MoE 718B

## 基本信息

**2025-05-30**，华为发布 **盘古 Ultra MoE**，一个总参数 **7180 亿（718B）**、单次推理仅激活 **390 亿（39B）** 的稀疏 MoE 语言模型，全部训练在华为昇腾 AI 计算平台上完成。随后于 **2025-06-20** 作为核心组件随**盘古大模型 5.5** 在 HDC 2025 上商用发布；**2025-10-15** 以 **openPangu-Ultra-MoE-718B-V1.1** 之名在 GitCode 平台开源权重与技术细节。

## 架构与训练

| 项 | 数值 |
|---|---|
| 总参数 / 激活参数 | 718B / 39B |
| 专家数 / 层数 / hidden | 256 专家 / 61 层 / 7680 |
| 训练硬件 | 6000 卡昇腾 NPU |
| MFU | 30.0% |
| 吞吐 | 1.46M tokens/s |
| 开源版训练数据量 | 约 19T tokens（从零训练） |
| 关键技术 | MLA（多头潜在注意力）、MTP（多 token 预测）、快慢思考可切换 |

## 成绩（华为公布）

通用与推理：AIME2024 **81.3%**、MATH500 **97.4%**、CLUEWSC **94.8%**、MMLU **91.5%**。
医疗：MedQA **87.1%**、MedMCQA **80.8%**，均高于 DeepSeek-R1。

盘古 5.5 层面的配套能力：

- **自适应快慢思考合一**：构建难度感知的快慢思考数据 + 两阶段渐进训练，简单问题敏捷回复、复杂问题深度思考，整体推理效率提升 **8 倍**。
- **DeepDiver（深度研究）**：长链难题合成 + 渐进式奖励，5 分钟内完成 10+ 复杂问答、生成万字以上专业调研报告。
- **低幻觉与 Agent**：在高效长序列、低幻觉、Agent 特性上同步升级。

## V1.1 开源版的变化

2025-10-15 开源的 openPangu-Ultra-MoE-718B-V1.1 相比上一版本：

- **Agent 工具调用能力显著增强**；
- **幻觉率进一步降低**；
- 模型权重与技术细节全面公开，采用 openPangu Model License。

## 争议：套壳指控（2025-07）

- 2025-07 初，GitHub 上名为 **HonestAGI** 的主体发布分析，称华为开源的**盘古 Pro MoE（72B）**与阿里 **Qwen2.5-14B** 的注意力参数分布存在"异常相关性"（平均 0.927），指控其通过 upcycling 而非从零训练得来。
- **2025-07-05**，华为诺亚方舟实验室声明否认：盘古 Pro MoE 是"基于昇腾硬件平台开发、训练的基础大模型，并非基于其他厂商模型增量训练而来"；同时承认部分基础组件代码实现参考了业界开源实践，并已按开源许可证要求标注版权声明。
- 阿里未回应，HonestAGI 身份至今不明。**该争议指向 72B Pro MoE，不是本页的 718B Ultra MoE**，但因同属盘古开源线常被一并讨论。

## 代际意义

- **纯昇腾训练的旗舰级验证**：718B 规模、MFU 30%，是"不依赖英伟达也能训出一线旗舰"在 2025 年的关键实证，与 2026 年美团的 LongCat-2.0（五万卡国产算力）构成同一叙事的两条路径。
- **盘古从行业走向通用基座**：3.0/5.0 时代盘古是"行业模型集合"，Ultra MoE 让它第一次有了可对比的通用旗舰规格。
- **开源旗舰的起点**：718B 权重开源为 2026 年 openPangu 2.0 的"更彻底开源"铺路。
