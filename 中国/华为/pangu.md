# 华为（盘古 Pangu / openPangu）

- 地区：中国
- 总部：广东深圳
- 成立：2020-03 田奇加入华为云组建团队，**2020-11 盘古在华为云内部立项**，2021-04-25 对外发布
- 定位：**AI for Industry** 起家（L0 基础 / L1 行业 / L2 场景三层），2025 起转向 **"昇腾原生训推 + 全栈开源"**；盘古既是华为云的行业模型，也是华为向外界示范"基于昇腾能训出世界一流模型"的样本
- 开源/闭源：**双轨**——闭源线为盘古 3.0/5.0/5.5 行业与云上模型；开源线为 **openPangu**（2025-06-30 起），含 7B / 72B / Ultra-MoE-718B-V1.1 / 2.0-Flash / 2.0-Pro，并逐步放出预训练、SFT、后训练 RL 代码
- 模型系列：五大基础模型（**盘古 NLP / CV / 多模态 / 预测 / 科学计算**）+ openPangu 开源语言线 + 行业大模型（矿山、气象、钢铁、政务、金融等）+ 科学计算子线（盘古气象、药物分子）
- 数据来源：百度百科（盘古大模型 / 盘古团队 / openPangu 2.0 / openPangu-2.0-Pro）、aiwiki（Huawei AI）、jademond（Pangu）、华为云盘古官网（pangu.huaweicloud.com）、新浪财经（2026-09-28）、ai345
- 状态：已完善（含 2026-09-28 openPangu 2.0 训练栈开源收官）

## 关键里程碑

- 2021-04：业界首个千亿参数中文预训练模型，AI for Industry 路线确立。
- 2023-07：**盘古 3.0** 三层行业架构，把大模型从"技术展示"推向"行业交付"。
- 2025-05-30：**盘古 Ultra MoE 718B**，首次证明纯昇腾集群可训出一线旗舰（MFU 30%）。
- 2025-06-30：**首次开源**（7B + 72B），盘古从封闭体系转向公共技术底座。
- 2025-10-15：Ultra-MoE-718B-V1.1 开源，把旗舰级权重交给社区。
- 2026-06-12 → 09-28：**openPangu 2.0 从发布到训练栈全量开源**，历时三个半月完成"更彻底开源"承诺。

## 分线说明

- **闭源行业线（盘古 3.0/5.0/5.5）**：按 L0/L1/L2 分层售卖，强绑定华为云与政企交付，参数不公开，是华为的行业收入与合规资产。
- **开源线（openPangu）**：定位"为业界用好昇腾提供最佳实践参考"，与昇腾硬件强绑定——在昇腾上是官方调优首选，在非昇腾硬件上迁移成本需自行评估。
- **科学计算线**：盘古气象、药物分子、风光水电新能源预测，是盘古区别于其他中国厂商的独特资产（Nature 级科学影响力 + 非洲/马达加斯加等海外落地）。
- **战略定位差异**：华为自 2026-09 明确"**AI 战略核心是算力、坚持硬件变现**"，盘古在集团内更多承担"验证昇腾 + 赋能自家产品"的角色，而非独立的模型商业化业务。

## 备注

- **口径差异**：盘古 5.5 与 Ultra MoE 同为 718B/39B，5.5 是产品版本号、Ultra MoE 是模型名；部分媒体将二者混用。
- **参数规模争议**：2026 年余承东曾解释"盘古只有 505B"是因为"华为昇腾自留的算力非常有限"——指 openPangu-2.0-Pro，与早期 718B 闭源旗舰不是同一条线，不要混比。
- **套壳争议**：2025-07 的 Qwen2.5-14B 相关性指控至今无第三方定论，诺亚方舟已公开否认；本页按"争议 + 官方否认"两说并记。
- **开源协议**：openPangu 使用华为自有许可证（openPangu Model License），与国内主流的 Apache 2.0 / MIT 不同，商用前需单独确认条款。
