# openPangu 2.0

## 基本信息

**2026-06-12**，在华为开发者大会（HDC 2026）主题演讲上，华为常务董事、终端 BG 董事长**余承东**正式发布开源盘古大模型的重大升级版本 **openPangu 2.0**，提出"做全世界最好的盘古大模型"，并公布分批开源路线图（自 2026-06-30 起陆续释放预训练代码、后训练代码、训练算子等 **7 大组件**）。

两个版本：

- **openPangu-2.0-Pro**：505B 总 / 18B 激活，512K 上下文，旗舰级，面向高复杂度 Agent 任务（推理与规划）。
- **openPangu-2.0-Flash**：92B 总 / 6B 激活（约 34T tokens 训练），512K 上下文，兼顾效果与推理成本，面向在线服务与规模化部署。

## 技术要点

- **稀疏配比设计**：通过稀疏配比降低运行负载，适配不同算力场景的部署需求；端侧面向麒麟芯片的 30B 模型额外应用量化剪枝。
- **DSA + SWA 独立分层混合架构**：在推理效率与长上下文表现之间取平衡；注意力沿用高效 MLA。
- **昇腾原生**：融合自研硬件内核、整机系统架构与训推一体化智能体强化学习算法，专为长上下文 Agent 任务打造；官方称**昇腾原生训练效率提升 30%**。
- **软硬协同**：模型、算子、框架协同设计，构成昇腾上的完整最佳实践参考。

## 开源范围（7 大组件）

分三批释放：模型结构 → 模型权重 → 技术报告 → 推理代码 → 预训练代码 → 后训练（SFT / RL）代码 → 训推算子。相比业内常见的"只放结构与权重"，openPangu 2.0 的开源范围显著扩展，被视为华为由"能力发布"走向"生态开放"的关键一步。

获取路径：GitCode / Ascend Tribe（ascend-tribe）开源社区下载权重与代码；华为云 MaaS 平台在线体验。

- 终端落地：小艺 Claw（鸿蒙系统级智能体）；面向麒麟芯片的端侧 30B 量化剪枝版本。

## 代际意义

- **从封闭到公共底座**：盘古由封闭体系转为行业共享的公共技术底座，降低企业与开发者的微调与二次开发门槛。
- **算力叙事的实证**：整条线全部基于昇腾 NPU 从零训练，是"国产算力可支撑旗舰模型"这一命题在 2026 年最直接的产品化证明。
- **开源深度的标杆**：连预训练与 RL 代码一并放出，在国内大厂开源中属于少见的深度；代价是生态强绑定昇腾，非昇腾硬件迁移需自行评估。

- **协议**：openPangu 使用华为自有 **openPangu Model License**，不是 Apache 2.0 / MIT，商用条款需单独确认。
