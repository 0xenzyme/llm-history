# Ling-1T / Ring-1T

## 基本信息

**2025-10**，蚂蚁集团百灵团队在**十天内连发两款万亿参数大模型**：

- **Ling-1T**（2025-10-09 发布并开源）——万亿参数**通用大语言模型**；
- **Ring-1T**（2025-10-14）——万亿参数**思考（推理）模型**；
- 前置：2025-09 已开源推理模型 **Ring-1T-preview**。

蚂蚁由此正式跻身**万亿参数模型阵营**，两款模型获 Yann LeCun 点赞（百家号报道口径）。

## 战略背景

这条线不是自然演进，而是一次组织级的加速。2025-01 DeepSeek R1 发布后，蚂蚁 CTO 何征宇用"**兴奋、紧迫感、羞愧**"三个词形容内部反应——同样是金融科技出身，能力不差，速度却落后了。

随后 10 个月内蚂蚁完成：

| 时间 | 动作 |
|---|---|
| 2025-01 | DeepSeek R1 发布，内部启动反思 |
| 2025-03 | 成立独立 AGI 组织 **Inclusion AI**（200+ 人，何征宇领头）；**验证国产设备训练可行性，1 万亿 Token 训练成本降至 508 万元** |
| 2025-04-25 | "Plan A" AI 人才专项 |
| 2025-06 | AQ 健康应用上线 |
| 2025-09 | Ring-1T-preview 开源 |
| **2025-10** | **Ling-1T + Ring-1T** |
| 2025-11-18 | 灵光发布 |

## 家族位置

百灵（Ant Ling）家族三条线：

| 线 | 定位 | 代表 |
|---|---|---|
| **Ling** | 通用大语言 | Ling-1T（2025-10）→ Ling-2.6-flash（2026-04） |
| **Ring** | 推理 / 思考 | Ring-1T-preview（2025-09）→ Ring-1T（2025-10）→ **Ring-2.5-1T**（2026-02，混合线性架构）→ Ring-2.6-1T（2026-05） |
| **Ming** | 全模态 | Ming-Flash-Omni 2.0（2026-02） |

截至 2025-11-06 世界互联网大会首展，家族已发布 **18 款**大模型，覆盖 10B–1T，且**已全系开源**。

## 代际意义

- **蚂蚁进入第一梯队的技术门票**：万亿参数是 2025 年下半年的入场门槛，Ling-1T / Ring-1T 让蚂蚁从"有技术但没表达出来"变成有自研旗舰可用。
- **为灵光提供底座**：灵光的"闪应用"需要在 30 秒内生成可运行代码，代码相对纯文本的**膨胀率约 5–6 倍**，对 Token 成本与生成速度要求极高——这正是 Ling-1T 与后续 Ling-2.6-flash 存在的直接原因。
- **"1 + N"路由架构的 1**：灵光底层不是单一模型，而是"1 个自研基座 + N 个第三方模型"，Ling-1T / Ring-1T 即其中的"1"。
