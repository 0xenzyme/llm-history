# Seed2.1

## 基本信息
- 发布时间：2026-06-23
- 类型：通用多模态基础模型（Pro 旗舰 + Turbo 规模化生产版）
- 定位：当前旗舰，Coding / Agent / VLM 三大方向"生产级质变点"

## 关键参数
- 架构：万亿参数级 MoE，被内部描述为"首个万亿参数 Gemini 式多模态基座"，团队成立至今训练的最大模型
- 变体：
  - Seed2.1 Pro：旗舰深度推理，对标 GPT-5.2，面向复杂 Coding 工程、长链路 Agent、多步骤科研任务、高价值生产场景
  - Seed2.1 Turbo：低成本低时延，效果比肩 Pro，适合高并发线上场景与企业日常业务
- 同代细分：Seed-2.0 Pro / Lite / Mini / Code（2026-02）→ Seed-2.1 Pro / Turbo（2026-06）

## 性价比
- Seed2.1 Pro 定价约每百万输入 token US$0.47，对比 GPT-5.2 的 US$1.75、Claude Opus 4.5 的 US$5.00（约为西方前沿模型的 1/3 ~ 1/10）

## 备注
- 与 Seed2.0（2026-02-14，首次跨代大版本）同属 2.x 代际；2.1 在 2.0 基础上于 Coding / Agent / VLM 方向质变，跨越"生产级质变点"。
- 2.0 被描述为"首次跨代大版本"，2.1 是最新旗舰。
