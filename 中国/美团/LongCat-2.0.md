# LongCat-2.0

## 基本信息

**2026-06-30**，美团发布新一代基础大模型 **LongCat-2.0**，**2026-07-06 正式开源**。它是**国内首个依托五万张国产算力卡集群完成预训练与推理全流程落地的万亿参数大模型**——训练与推理路径上不含英伟达硬件。

规格：MoE 架构，**总参数 1.6 万亿，平均激活约 480 亿**（动态范围 33B–56B），**原生支持 1M 超长上下文**，预训练数据规模超 **30T tokens**（中英多语言 + 代码）。

## 架构要点

| 机制 | 作用 |
|---|---|
| **ScMoE 跨层快捷连接** | 跨层快捷连接架构，降低 MoE 通信与访存开销 |
| **零计算专家机制** | Token 级动态计算预算：简单 token 走近似免费子网络，把算力花在真正需要的输入上 |
| **LSA（LongCat Sparse Attention）** | 演进自 DeepSeek Sparse Attention；流式感知索引 + 跨层索引（相邻层共享索引结果）+ 分层索引（两阶段筛选），把 1M 上下文计算量从平方级降至近线性 |
| **N-gram Embedding** | 135B 参数、与专家布局正交，嵌入容量扩约 100×，捕捉局部 token 关系并降低大 batch 解码的显存 I/O；继承自 LongCat-Flash-Lite 线 |
| **MOPD 后训练** | Agent / Reasoning / Interaction 三组专家隔离微调，推理时由门控网络动态融合 |

## 训练工程（国产算力上的系统工程）

| 指标 | 数值 |
|---|---|
| 集群规模 | 5 万张国产算力卡 |
| 日均故障率 | 万分之 15.7 → **万分之 4.4** |
| MFU | 17.8% → **27.68%** |
| 稳态日吞吐 | 7170 亿 → **1.12 万亿 tokens/day** |
| 正确性 | 自研确定性算子 + Bitwise 一致性验证 |
| 稳定性手段 | HCCL 异常处理、弹性扩缩卡、自动故障恢复 |

推理侧：大规模专家并行聚合访存带宽支撑万亿 MoE 低延迟解码；零计算专家机制融入专家并行通信流程（路由到零专家的 token 免传输与计算）；算子调度 + 提前下发 + 权重预取降低等待开销。

## 发布前：匿名期 "Owl Alpha"

2026-04 底上线 **LongCat-2.0-Preview**，在 OpenRouter 以匿名代号 **"Owl Alpha"** 测试。截至 6 月底总调用量曾跻身全球前三；月调用量在 **Hermes 第一、Claude Code 第二、OpenClaw 第三**。2026-06-30 由美团公开身份（VentureBeat 报道），GitHub、Hugging Face 与自有平台同步上线。

## 开源范围

- 权重：**MIT** 协议（允许免费商用），BF16 / FP8 / INT8 多精度；
- 推理：同步开源针对国产算力极致优化的推理成果（2026-07-12）；
- 适配：华为昇腾、摩尔线程、沐曦等国产芯片厂商于 2026-07-06 同日完成推理适配。

## LongCat-2.5-Preview（2026-09-25）

在 LongCat API 平台与 longcat.chat 上线，规格延续 1.6T / ~48B 激活 / 原生 1M，最大输出 **128K**：

- **新增原生图像理解**：图文混合理解、跨模态问答、复杂视觉推理；可解析表格、流程、界面草图转代码、架构图转描述，去掉"额外挂视觉模型做翻译"这一失真环节。
- **定位转向长程任务**：从 Agentic Coding 扩展到终端、浏览器、GUI、电子表格、设计工具的自主操作。
- **接入**：OpenAI / Anthropic 兼容端点；适配 Codex、OpenCode、OpenClaw、CatPaw、Claude Code、Hermes、Kilo Code。
- **商业化**：限时输入约 $0.30 / 输出约 $1.20（每百万 token），向老用户赠送 500 万免费 tokens。
- **本轮不公布跑分**——与 2.0 发布时"晒跑分、对标友商"的做法明显不同，被视为从"证明更强"转向"顺手好用"的实用主义信号。

## 代际意义

- **国产算力的完整闭环证明**：首次把"五万卡国产集群 → 万亿参数预训练 → 推理部署"整条链路跑通并开源，对出口管制叙事有直接冲击。
- **效率优先的架构哲学**：零计算专家 + LSA + N-gram Embedding 三件套都指向同一件事——让万亿模型在真实任务上更便宜，而不是更大。
- **从模型到 Agent 平台**：CatPaw（2026-07-28）与 2.5-Preview 的多模态长程能力，把 LongCat 从"一个开源模型"推进为"一套可交付的 Agent 工作流底座"。

## 备注

- **硬件路线差异**：同系列 LongCat-Flash（2025-09）用英伟达 H800 训练，LongCat-2.0 完全不用英伟达——两代不应笼统称为"全国产路线"。
- **2.5-Preview 能力待验**：官方本轮未给任何基准分数，"Agent 能力提升"目前只是定位表述。
- **调用量数据**：OpenRouter 排名为平台观测数据，非审计口径。
- **内部收敛传闻**：2026-07 媒体称美团内部收敛第三方商用模型接入，未见官方确认。
