# 星火 X2

## 基本信息

**星火 X2** 于 **2026-02-11** 发布（部分官方材料只写"2026 年 2 月"），采用 **293B MoE 稀疏架构** + 权重量化与低精度训练等工程化创新，**基于全国产算力训练**，并落地**国产大 EP 并行部署**；官方称推理性能较 **X1.5 提升 50%**，通用能力全面升级、整体对标国际顶尖模型。

## 关键成绩

- 数学、推理、语言理解与智能体能力"媲美国际最优"；130+ 多语言综合能力继续提升，拉美、东盟等重点语种保持业界领先。
- 多尺寸中小模型同步升级，在办公本、翻译机、汽车座舱交互等场景核心效果显著提升。
- 行业能力：医疗、教育、司法、汽车交互、企业智能体应用全面升级，医疗/教育垂直领域保持业界领先。
- 星辰 Agent 平台整合语音交互、语音识别、图像理解等百余种能力，**智能体数量超 130 万**。

## 系列分支

| 变体 | 时间 | 说明 |
|---|---|---|
| X2 Lite / Pro / Max / Ultra | 2026-02 起 | 当前 API 四档；Lite 完全免费、永久开放，通用任务对标 DeepSeek V3.2 Lite |
| X2-Flash | 2026-04 | 基于国产算力训练，支持长上下文，面向智能体、代码等复杂任务优化推理效率与调用成本 |
| X2-VL | 2026-06 | 多模态分支：图文理解、视觉推理、复杂文档解析、图表理解 |
| X1 升级版 | 2026-07-25 | 底座多语言扩展至 130+ 语种（与 X2 并行维护） |

## 代际意义

- **工程化代际**：X2 的叙事重点不在参数规模，而在"全国产算力上把 MoE 训得动、部署得下"——大 EP 并行 + 量化 + 低精度训练是国产算力工程成熟的标志。
- 与 X1 的小参数路线一脉相承：293B MoE 相对同期万亿级旗舰仍属小体量，靠效率与行业数据取胜。
- 产品线化：X2 之后星火明确按 Lite/Pro/Max/Ultra 分档售卖，Lite 免费成为获客入口。
