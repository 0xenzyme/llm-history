# 京东（JoyAI / 言犀）

- 地区：中国
- 总部：北京
- 成立：2021 年推出十亿级模型 K-PLUG，2022 年百亿级 Vega，**2023-07-13 正式发布"言犀大模型"**；2025-07 品牌升级为 **JoyAI**
- 定位：**"源于产业、服务产业"**——不追通用榜单，把模型养在京东自己的供应链场景里再卖给产业；2026 年起明确"**AI 进入物理世界**"三阶段（数字智能 → 附身智能 → 物理智能）
- 开源/闭源：**混合**——闭源为言犀/JoyAI 商业服务与云上 API；开源侧自 2026 年起密集放出 JoyAI-LLM-Flash、JoyAI-Image-Edit、JoyAI-VL-Interaction、JoyAI-Echo 等，并开源智能体 **JoyAgent** 与人类视角数据集
- 模型系列：**JoyAI 基础模型矩阵**（3B–750B，覆盖语言 / 语音 / 图像 / 视频 / 数字人）+ 垂类（JoyIndustrial 工业、京医千询医疗、超脑物流）+ 智能体（JoyAgent、JoyInside）+ 具身数据基础设施（EgoLive）
- 数据来源：百度百科（JoyAI 基座大模型 / 京东AI）、新华网 / 人民网（2023-07-13 JDD 报道）、凤凰网科技·IT之家（2026-02-14）、澎湃新闻《大模型之家热力榜》、爱企查 JoyAI 词条

## 关键里程碑

- 2023-07：**言犀大模型**，把"30% 供应链原生数据"作为差异化叙事，避开通用榜单竞争。
- 2025-07：**品牌升级 JoyAI**，从"客服/文案工具"升级为全尺寸多模态模型矩阵 + 智能体品牌。
- 2026-02 → 06：**连续四个月开源**（LLM-Flash → Image-Edit → VL-Interaction），从语言补到实时视频交互。
- 2026-09：**物理 AI 加速计划**，把模型能力明确导向具身智能与机器人产业。

## 分线说明

- **闭源产业线（言犀 → JoyAI 商业服务）**：面向零售、物流、金融、健康、政务的 To B 交付，参数与细节不公开，是京东云的收入来源。
- **开源线（JoyAI 模型矩阵）**：2026 年起以 Modified MIT 等协议放出，重点是**实时视频交互**与**图像编辑**这两类电商直播/内容场景直接可用的能力，而非通用跑分。
- **智能体与硬件（JoyAgent / JoyInside）**：把模型能力封装成可嵌入第三方硬件的交互层，是"附身智能"阶段的落地抓手。
- **策略差异**：京东**不参与通用基座军备竞赛**，用自家供应链场景养模型、再卖给产业；2026 年后把重心压到具身智能数据基础设施——赌的是"数据是物理 AI 的瓶颈"这一判断。
