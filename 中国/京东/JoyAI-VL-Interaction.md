# JoyAI-VL-Interaction

## 基本信息

**2026-06**，京东全栈开源**实时视频视觉语言交互模型 JoyAI-VL-Interaction**。它改变了传统多模态模型"**一问一答**"的交互模式，具备**持续观看实时画面、自主判断、主动响应**的流式交互能力——模型不再等待提问，而是盯着画面自己决定何时说话。

开源范围不止权重：**模型权重 + 交互数据集 + 训练方案 + 完整可部署系统**，并获得 **vLLM-Omni 的 Day-0 原生支持**。

## 为什么重要

- **交互范式变化**：从"用户上传图像 → 模型回答"的一次性问答，转向"模型持续观察视频流 → 主动发起响应"的常驻观察模式。这是多模态模型从工具走向"在场助手"的关键一步。
- **全栈而非单点**：连同数据集与训练方案一起放出，意味着第三方可以复现"主动响应"这类难以从论文复刻的行为，而不只是拿到一个能跑的权重。
- **生态卡位**：vLLM-Omni Day-0 支持，说明它在开源推理栈里被当作一类新的模型形态（实时交互）来对待，而非普通 VLM。

## 与 JoyAI 矩阵的关系

| 模型 | 时间 | 能力 |
|---|---|---|
| JoyAI-LLM-Flash | 2026-02 | 语言基座（48B/3B，工具调用与推理） |
| JoyAI-Image-Edit | 2026-04 | 文生图 / 图像理解 / 指令编辑 |
| **JoyAI-VL-Interaction** | 2026-06 | **实时视频流的主动交互** |
| JoyAI-Talker | 2026-07 | 实时语音交互 |
| JoyAI-Video-Edit | 2026-07 发布 / 08-05 开源 | 实时视频编辑（电商直播"边播边改"） |

JoyAI-VL-Interaction 与 JoyAI-Talker 组合，构成"实时看 + 实时说"的完整链路，正是京东直播、客服、导购场景最需要的能力组合。

## 场景

电商直播（边播边理解画面并主动提示）、智能客服（持续观察用户操作）、导购与巡检等需要"模型一直在场"的视频场景；也是 JoyInside 附身智能平台为家电、玩具、机器人注入交互能力的技术基础之一。
