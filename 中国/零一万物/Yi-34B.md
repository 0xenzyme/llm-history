# Yi-34B

## 基本信息

**2023-11-06**，零一万物正式开源发布首款预训练大模型 **Yi-34B**：训练参数 **340 亿**的**双语（中英）基础模型**，支持**超长 200K 上下文窗口**，可处理约 40 万字文本。模型在阿里云魔搭 ModelScope 首发，同时在 **Hugging Face、ModelScope、GitHub** 三大平台上线并开放商用申请。

发布 Yi-34B 的同时，零一万物已完成下一个千亿参数模型的训练启动。

## 成绩与影响

- **Hugging Face OpenLLM Leaderboard（pretrained）登顶**：预训练开源模型排名全球第一；
- **C-Eval 中文权威榜单**：公开访问的模型全球第一；
- 与 Yi-6B 共同构成"双语基座"双子，是**中国开源权重 LLM 可行性在大规模上的早期证明**——Yi-34B 发布于 2023 年末，早于后来 DeepSeek、Qwen 引领的中国开源权重浪潮。

## 代际意义

- **中国开源权重路线的先声**：在"百模大战"初期，34B 规模直接开源可商用并不多见，Yi-34B 是这一路径的标杆性release。
- **长上下文的早期探索**：200K 在 2023-11 属于第一梯队（与同期 Baichuan2-192K 相当），为中文长文档场景提供了早期可用的开源选项。
- **品牌延续性**：Yi-Coder（1.5B/9B + 128K）至今仍在小团队本地代码补全场景被使用，是零一万物关停公共 API 后仍有生命力的资产。

## 备注

- **API 已停**：2026-08-10 公告、**2026-09-03 24:00 起**零一万物大模型开放平台停止模型体验与 API 调用；Yi-34B 权重仍可从开源平台获取并自行部署。
- **"全球 SOTA"口径**：发布时"预训练开源模型排名全球第一"指 HF OpenLLM Leaderboard 的 pretrained 分项，非综合能力，引用时须注明。
- **命名**：Yi 取自"一"的拼音；官方释义为"Y 上下颠倒形同汉字'人'，结合 AI 的 i，代表 Human + AI"。
