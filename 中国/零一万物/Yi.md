## 关键里程碑

- 2023-11：**Yi-34B 登顶 HF 开源榜**，是"中国开源权重 LLM 可行性"的早期证明，先于 DeepSeek/Qwen 的大规模开源浪潮。
- 2024-10：**Yi-Lightning 全球第六、$0.14/M**，证明中国实验室能在价格上对标并低于 OpenAI 同档。
- 2025-01 起：**转向 To B**——与阿里云共建产业大模型实验室，发布万智平台。
- 2026-08/09：**关停公共开放平台**，彻底剥离 C 端与独立开发者业务，为 2027 年港股 IPO 做资本结构准备。

## 分线说明

- **开源基座线（Yi-34B / 9B / 6B / 1.5 / Coder）**：仍是零一万物对外最有生命力的资产——Yi-Coder 因"体量小 + 128K + 52 语言"在小团队本地代码补全场景中长期使用。
- **闭源旗舰线（Yi-Large / Yi-Lightning）**：曾是最赚钱的 API 业务，2026-09 随开放平台一并关停。
- **企业平台线（万智 / 万策 / 万知）**：2025 年后的真正重心，从"卖 token"转向"卖行业解决方案与决策 AI"。
- **策略差异**：与 DeepSeek、Qwen、Kimi 相比，零一万物的**发布节奏在 2025–2026 明显放缓**，基座线基本停在 2024-10；公司把生存希望押在 To B 交付与 IPO，而非模型能力竞赛——这是"六小虎"中最明确的**退出基座竞争**案例。
