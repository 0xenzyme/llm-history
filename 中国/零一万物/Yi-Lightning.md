# Yi-Lightning

## 基本信息

**2024-10-16**，零一万物发布**全球 SOTA 的新旗舰模型 Yi-Lightning**，与其 To B 战略下的首发行业应用产品"AI 2.0 数字人"同日公布。它是 Yi 家族的**成本效率旗舰**：

- **LMSYS Chatbot Arena 全球第六、中国第一**；
- 定价 **$0.14 / 百万 tokens**——同期 GPT-o1-mini 为 $0.26/M，约为其一半；
- 另设更便宜的 **Yi-Lightning-Lite** 变体，面向高吞吐场景。

## 为什么它重要

Yi-Lightning 证明了两件事：

1. 中国实验室可以在**价格上对标并显著低于 OpenAI 同档产品**，同时进入 Chatbot Arena 前十；
2. 在"质量接近 GPT 级、成本减半"的档位上存在真实的市场缺口——这一档后来成为 Yi API 的主力。

Yi-Lightning 2（2026-03，第三方记录）延续这一路线：多语言推理较初代约 **+22%**，编码能力拉近与 GPT-5.4 / Claude Sonnet 4.6 的差距，输入约 **$0.18/M**；截至 2026 Q1，据称占 Yi API token 量的 **71%**。多语言覆盖扩展到韩语、日语、越南语、印尼语、泰语——Yi 的训练语料对这些亚洲语言的覆盖高于 Llama、Mistral 等开源家族。

## 部署特征

成本效率直接转化为部署广度：Yi-Lightning 2 被大量第三方产品内嵌而不显式标注模型名；在成本敏感的客服场景、APAC 与中东的**主权 AI 部署**中占比明显。

## 当前状态

**2026-08-10** 零一万物公告称，因产品与服务体系升级、进一步聚焦企业级人工智能解决方案，大模型开放平台将逐步停止在线体验、API 调用及充值服务：

- 即日起停止新用户注册与充值；
- **2026-09-03 24:00 起停止模型体验与 API 调用**；
- 退款申请窗口开放至 **2026-12-03 24:00**。

这意味着 Yi-Lightning 作为公共 API 产品**已于 2026-09-03 终止服务**。

## 代际意义

- **价格战的早期样本**：2024-10 的 $0.14/M 是中国厂商以价格切入全球市场的标志性报价之一，为后来 DeepSeek 等的价格战提供了先例。
- **多语言护城河**：Yi 在韩/日/越/印尼语上的表现优于同规模开源家族，是其在 APAC 与中东市场被持续部署的技术原因。
- **终局说明问题**：即便有性价比与多语言优势，零一万物仍在 2025–2026 放缓基座迭代，并于 2026-09 关停公共 API——说明**在中国市场，仅有"便宜 + 够用"不足以支撑独立基座业务**。
