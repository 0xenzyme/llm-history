# ERNIE 5.0（文心大模型 5.0）

## 基本信息

ERNIE 5.0 于 **2025-11-13** 百度世界大会以 Preview 形式发布（ERNIE-5.0-Thinking-Preview / Latest 同步上千帆平台），**2026-01-22** 发布正式版。官方定位"原生全模态大模型"：不是给文本模型外挂各模态编码器，而是在预训练阶段就用统一自回归架构对**文本、图像、音频、视频联合建模**。

## 关键参数

- **2.4 万亿总参数**，超稀疏 MoE，**激活比低于 3%**（单次推理实际激活约数百亿参数）——兼顾规模与推理经济性。
- 原生全模态：全模态理解与生成，支持多种信息的输入与输出。
- 延续飞桨 PaddlePaddle 训练与部署；正式版未公开详细技术报告，官方以能力演示为主。

## 关键成绩

- Preview 版 **ERNIE-5.0-Preview-1022** 于 **2025-11-08** 登 **LMArena 文本榜全球并列第二、中国第一**（创意写作、复杂长问题理解、指令遵循突出）。
- 正式版 **ERNIE-5.0-0110** 于 2026-01 以 **1460 分**进入 LMArena 文本榜全球前十。
- 官方称语言与多模态理解能力超越 Gemini 2.5 Pro、GPT-5-High，"稳居国际第一梯队"；第三方口径下 5.0 列 LMArena 文本榜国内第一、全球第八。

## 代际意义

- 中国首个公开宣布**参数突破 2.4 万亿**的超大模型，把"原生全模态"从 4.5 的多模态理解推进到**统一预训练 + 生成**。
- 与同期国产路线差异明显：华为/讯飞主打全国产算力，百度主打昆仑芯 + 飞桨的全栈自用闭环；5.0 是这条全栈路线的最大规模验证。
- 后续 5.1（2026-05-09）用"多维弹性预训练"把总参压到约 1/3、预训练成本压到业界同规模的约 6%，是 5.0 的"效率化"续代而非重训。
