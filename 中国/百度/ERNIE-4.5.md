# ERNIE 4.5

## 基本信息

**2025-03-16**，百度同日发布**文心大模型 4.5**（新一代原生多模态基座）与**文心大模型 X1**（首个自主调用工具的深度思考模型），并在文心一言官网免费开放。X1 的 API 定价较 DeepSeek-R1 再降一半（输入约 0.002 元/千 tokens）。**2025-04-25** Create2025 上追加 **4.5 Turbo / X1 Turbo**；**2025-06-30** 正式开源 4.5 系列共 **10 款模型**（Apache 2.0），标志百度从闭源走向开源。

## 技术要点

- **FlashMask 动态注意力掩码**：加速灵活注意力掩码计算，提升长序列建模与训练效率。
- **多模态异构专家扩展**：按模态构建异构专家 + 自适应模态感知损失，解决不同模态梯度不均衡。
- **时空维度表征压缩**：压缩图片/视频语义表征，提升多模态训练效率与长视频知识吸收。
- **基于知识点的大规模数据构建**：知识分级采样 + 稀缺知识点定向合成，显著降低幻觉。
- **自反馈 Post-training**：融合多种评价方式的迭代式后训练，提升 RL 稳定性与对齐。
- 开源旗舰 ERNIE-4.5-300B-A47B-Base 在 **28 项基准中的 22 项**超过 DeepSeek-V3（671B-A37B-Base）。

## 关键成绩

- 4.5 多模态能力优于 GPT-4o，多项基准优于 GPT-4.5 与 DeepSeek-V3，**平均分 79.6 分**（GPT-4.5 为 79.14）。
- X1 Turbo 于 2025-05 在中国信通院大模型推理能力评估中获最高级"4+ 级"。
- 4.5 Turbo：多模态理解较前代提升 30%+，训练吞吐 5.4×、推理吞吐 8×，调用成本降 80%。
- 开源 10 款含 47B / 3B 激活的 MoE 模型与 0.3B Dense 模型，覆盖端侧到数据中心；同日中兴 AiCube 智算一体机完成全系适配。
- 衍生：ERNIE-4.5-21B-A3B-Thinking 曾登上 Hugging Face 全球模型趋势榜榜首（2025）。

## 代际意义

- **战略反转**：李彦宏此前长期偏好闭源，2025-02 宣布开源计划（称开源"让技术扩散更快"），2025-04-01 文心一言全面免费，2025-06-30 兑现开源——这是在 DeepSeek 重设中国前沿模型价格与开源预期之后的被动也是主动的路线切换。
- **原生多模态**取代"文本模型 + 外挂编码器"，直接铺垫了 5.0 的"原生全模态统一建模"。
- **X 线独立**：X1 成为百度推理/思考模型的独立后缀（X1 → X1.1 → X1 Turbo），与数字版本主线并行。
