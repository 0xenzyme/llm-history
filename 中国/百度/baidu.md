# 百度（文心 ERNIE）

- 地区：中国
- 总部：北京
- 成立：2000-01-01
- 定位：**全栈自研四层架构**（昆仑芯 → 飞桨 PaddlePaddle → 文心大模型 → 搜索/应用），中文知识与合规标杆；国内首个面向公众开放的通用大模型
- 开源/闭源：2025 年前全闭源；**2025-06-30 起 ERNIE 4.5 系列以 Apache 2.0 开源**（李彦宏战略反转），此后走"闭源旗舰 + 开源生态"双轨
- 模型系列：文心 ERNIE（单系列；含 X 深度推理线 + 图像/文档解析/语音等分支）
- 数据来源：百度百科（文心一言 / 文心大模型 4.5 / 文心大模型算法 / Ernie）、aiwiki（baidu / ernie / robin_li）、百度智能云千帆"模型更新记录"、三个皮匠报告（百度AI / 文心一言）
- 状态：已完善（含 2026-05-09 文心 5.1）
