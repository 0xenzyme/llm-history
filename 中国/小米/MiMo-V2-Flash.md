# MiMo-V2-Flash

## 基本信息

**2025-12-17**，在小米"人车家全生态"合作伙伴大会上，**罗福莉（MiMo 大模型负责人）首次公开亮相**，发布并开源专为推理效率自研的 **Xiaomi MiMo-V2-Flash**（309B 总 / 15B 激活 MoE），同时阐述小米对下一代智能体（Agent）的愿景。这是小米在 MiMo-7B（2025-04-30）之后的**首个大规模开源权重模型**，也是"发布即开源"策略的正式起点。

## 技术要点

- **MoE**：309B 总参数，256 个专家、每次激活 8 个，激活参数 15B。
- **5:1 混合注意力**：滑动窗口注意力（SWA）与全局注意力按 5:1 协同，配合可学习注意力汇聚偏置。
- **多层 Token 预测（MTP）** + **多教师在线策略蒸馏（MOPD）**：官方称实现最高 **2.6× 推理加速**。
- 定位"推理效率优先"：为后续 V2-Pro / V2.5-Pro / V2.6 的 1M 上下文与 Agent 长程任务打工程底子。

## 代际意义

- **路线拐点**：小米 2023 年曾明确"不做通用大模型"，2024 年底成立 Core 团队转向自研基座，V2-Flash 标志其从"端侧小模型"跨入"开源权重前沿"。
- **罗福莉效应**：前 DeepSeek 核心成员带队后，MiMo 明显转向"大规模 RL + 开源权重 + Agent 能力"的 DeepSeek 式打法。
- **开源策略定型**：此后 V2.5 系列（2026-04-28，MIT）、V2.6 系列（2026-09-22，MIT）均延续"发布即开源"，并进一步开源 RL 环境与训练框架。
