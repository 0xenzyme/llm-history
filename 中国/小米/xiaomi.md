# 小米（MiMo / MiLM）

- 地区：中国
- 总部：北京
- 成立：2010-04-06（小米集团）
- 定位：**"人车家全生态"**驱动；端云结合、轻量化本地部署起家，2025 年起转向**自研 Agent 基座 + 大规模开源权重**

- 模型系列：MiMo（Agent 基座主线）+ MiLM（端侧轻量线）+ 语音/视觉/代码分支
- 数据来源：百度百科（小米大模型 / MiMo 基座大模型）、Xiaomi MiMo 开放平台"模型发布"记录、Artificial Analysis、origami、今日头条/海淀融媒、高盛研报（转引）

- 2025-11：罗福莉加盟，MiMo 路线定型为"面向复杂 Agent 任务的基座"。
- 2025-12-17：**MiMo-V2-Flash**（309B/15B）发布即开源，大规模开源权重路线起点。
- 2026-03-19：V2-Pro / V2-Omni / V2-TTS 三款同发，补齐全模态与语音。
- 2026-09-22：**MiMo-V2.6** 系列，AA 智能指数开源权重第一、国产第一。

## 分线说明

- **MiLM 线**：端侧轻量（0.3B–6B）与云端（13B/30B），服务"人车家全生态"与隐私优先场景；技术含 TransAct 结构化剪枝（8% 训练计算量从 6B 剪出 4B）、端侧量化（量化损失降低 78%）、投机采样/BiTA/Medusa 加速。
- **MiMo 线**：面向复杂 Agent 任务的基座，全系 MoE，1M 上下文，逐步补齐 TTS / ASR / Omni / Code 分支，且**坚持"发布即开源"（MIT）**。
- **策略差异**：不同于多数中国厂商的"闭源旗舰 + 开源小模型"，小米把**旗舰本身开源**，靠 API（含 Ultraspeed 高价低延迟档）与硬件生态变现。
