# MiMo-V2.6

## 基本信息

**2026-09-22**，小米正式发布并开源 **MiMo-V2.6 系列**三款模型，延续"发布即开源"策略，同时推出 **MiMoDesktop 桌面客户端正式版**：

- **mimo-v2.6-pro**：全模态旗舰推理模型（1.02T 总 / 42B 激活），覆盖复杂项目、长程任务、高价值工作、网络安全与科研。
- **mimo-v2.6-flash**：全模态高效推理模型（309B / 15B），面向专业办公高频调用与规模化任务。
- **mimo-v2.6-pro-ultraspeed**：旗舰性能 + 最高 20× 推理速度（官方模型页口径），服务强实时交互；价格为 Pro 的 10×。

## 关键成绩

- **Artificial Analysis 综合智能指数 46（v4.3.2）**：**开源权重模型第一、国产模型第一**，超过 Kimi K3（44）与 GLM-5.3（45），且是该榜总榜前五中唯一的开源权重模型（Hugging Face CEO 转发评价 "Banger!"）。
- 对照 Claude Opus 5（模型卡数据）：AutomationBench 53.1 vs 50.3；Terminal-Bench 2.1 89.9 vs 89.1；DeepSWE 71.9 vs 74.0；OSWorld-Verified 82.0 vs 83.4；更难的 Terminal-Bench 4.0 为 34.9 vs 49.0（明显落后）。
- 官方实测单任务成本约 **$0.13**（AA 智能指数单任务成本榜）。
- 两个模型在训练任务上的平均通过率分别提升 25% 与 12%；具备一定科研与网络安全攻防能力（以 Co-Scientist 角色协助 MOF 材料设计、在 Lean 4 中完成 Li-Yorke 定理形式化）。

## 训练要点（大规模 RL）

- **2026-09-17 起连续 6 天公开直播 RL 后训练过程**：RL 后训练合计成本超 **347 万美元**（Flash 约 85 万、Pro 约 262 万），累计约 **75 万条轨迹**——海外技术圈称其为"最具分量的大规模 RL 公开资源之一"。
- 大 Batch + 全异步架构：单次更新 **1568 个样本**，支持 1M 上下文训练，单步 3.5–3.7B tokens。
- 覆盖 Code / General / Visual / Cyber 等多方向任务环境；组内相对比较为长程 RL 提供奖励信号；冻结 Router 抑制漂移，并建立 Reward Hacking 防线。
- 同步开源：**MiMo-V2.6-Distill-Qwen-9B**、7000+ 高质量 RL 任务环境、端到端 RL 训练框架与轻量化可组合 Harness。

## 代际意义

- **开源旗舰登顶**：AA 榜单前五中唯一的开源权重模型，把"开源 ≈ 略落后"的惯例打破一格（但仍明确落后于 Fable 5.1 / GPT-6 Astra 等当期闭源顶流）。
- **全模态补齐**：V2.6 是开源阵营中少见的 Pro 级全模态（文本/图/视频/音频单模型输入），补齐开源 Pro 档短板。
- **RL 透明度**：把大规模 RL 的成本、轨迹量与环境资源公开，是 2026 年少见的做法，直接构成技术信誉资产。
